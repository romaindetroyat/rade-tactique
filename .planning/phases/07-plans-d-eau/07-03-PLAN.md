## Décisions de planification

- L’exclusion du SHELL et le manifeste sont faits ICI, dans le même plan que les premiers fichiers `data/brest.*` : sinon `npm run stamp` les mettrait dans le précache de tous les téléphones (+5 Mo à chaque mise à jour, anti-motif de l’étude).
- Toulon n’est jamais régénéré (ses entrées ne sont pas dans le dépôt) : les outils gardent les valeurs de Toulon comme défauts quand on ne leur passe pas de configuration, et la garde des données (tools/gardes-toulon.mjs) prouve que `data/*` de Toulon n’a pas bougé.
- OpenStreetMap : essayer Overpass d’abord (requête de l’étude § 1.2 : `natural=coastline`, `man_made~breakwater|pier|groyne`, `landuse~residential|industrial|commercial|military|harbour`, boîte (48.20,−4.70,48.45,−4.18)) ; si Overpass est injoignable depuis l’environnement, utiliser l’API principale par boîtes, comme l’étude l’a fait (boîtes de 0,04° × 0,02°, coupées en deux sur refus pour trop de nœuds, pause d’une seconde entre requêtes, arrêt sur 429/509, en-tête User-Agent générique sans nom ni adresse), dédoublonnage des chemins par identifiant. La méthode effectivement utilisée est écrite dans docs/brest-sources.md.
- Graines de remplissage de la mer tirées de la bathymétrie (tout point à plus de 3 m sous le zéro des cartes), jamais écrites à la main (Iroise, rade et baie de Douarnenez sont des bassins distincts, étude piège 2) ; géoréférence du GeoTIFF EMODnet lue dans la configuration (pour la requête de l’étude : −4.70 ; 48.45 ; 1/960, piège 3).
- Entrées téléchargées : hors du dépôt, un dossier neuf par source (`tiles/`, `emodnet/`, `osm/`, `meteo/`) sous un dossier de travail de l’exécutant ; elles sont des données non fiables : lues par les outils (`python3 -I`), jamais exécutées ; leurs tailles et SHA-256 vont dans docs/brest-sources.md. - Format du manifeste `data/venues.json` : `{ "v": 1, "venues": { "brest": { "pack": "<10 hex>", "bytes": <total>, "files": [{ "path": "data/brest.meta.json", "bytes": …, "sha256": "<64 hex>" }, …] } } }`, fichiers triés ; `pack` = 10 premiers hex du SHA-256 de la liste des (chemin, sha256) ; les fichiers `.md` sont exclus.
